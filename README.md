# Ripplytics Web

Official marketing website for **Ripplytics Systems (OPC) Private Limited**.

## Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS v4
- Deployed on Vercel

## Local development

```bash
npm install
npm run dev
```
